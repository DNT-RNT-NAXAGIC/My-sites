# ԴՆԹ և ՌՆԹ — ինտերակտիվ դպրոցական նախագիծ

Next.js + Three.js + React Three Fiber։ Հայերեն ինտերակտիվ 15 սլայդ և առանձին 3D լաբորատորիա։

## Տեղային գործարկում

```bash
npm install
npm run dev
```

Բացեք http://localhost:3000։

## Կառուցում

```bash
npm run build
npm start
```

## Տեղակայում Vercel-ում

1. Ներմուծեք այս GitHub նախագծի պանակը կամ պահոցը Vercel-ում։
2. Եթե նախագիծը գտնվում է `My-sites` պահոցի `dna-rna-lab` պանակում, ընտրեք Root Directory = `dna-rna-lab`։
3. Framework preset՝ Next.js, Build Command՝ `npm run build`։

## Բովանդակության խմբագրում

Սլայդների տեքստերը, թեստի հարցերը և աղբյուրները պահվում են `app/page.tsx`-ի `slides`, `quiz` և `sources` տվյալներում։ Հեղինակի և դպրոցի դաշտերը պահվում են `projectInfo` օբյեկտում։

## Գիտական նշումներ

- 99.9% նմանությունը համեմատության տարածված պարզեցում է. NHGRI-ն նշում է, որ ամբողջական գենոմային տարբերակները հաշվի առնելիս գնահատականը մոտ 99.6% է։
- ԴՆԹ-ի կառուցվածքի պատմական բացահայտումը ներկայացված է որպես մի քանի հետազոտողների աշխատանքի արդյունք։
- Սկզբնական PPTX-ի որոշ ձևակերպումներ առանձին նշված են վերանայման համար. դրանք լուռ չեն փոխվել։
- Բացառված թեմաները ինտերֆեյսում չեն բացատրվում։
